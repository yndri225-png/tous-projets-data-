# 📊 Projet 1 : Analyse des Ventes avec Power Query

## Objectif

Construire un processus automatisé permettant de nettoyer, transformer et analyser des données de ventes provenant de plusieurs fichiers Excel.

## Compétences développées

- Importation et consolidation de données
- Nettoyage de données
- Suppression des doublons
- Transformation de données
- Fusion de tables
- Création de colonnes calculées
- Analyse du chiffre d'affaires
- Comparaison aux objectifs commerciaux
- Actualisation automatique des données

## Outils utilisés

- Microsoft Excel
- Power Query

## Résultats

✅ Fusion des ventes de plusieurs mois

✅ Calcul automatique du chiffre d'affaires

✅ Suivi des performances par boutique

✅ Comparaison CA / Objectifs

✅ Modèle entièrement actualisable

# ⛏️ Projet 2 : Gestion des Activités Minières au Mali

## Objectif

Concevoir une base de données PostgreSQL simulant la gestion des activités minières au Mali.

## Structure de la base de données

La base de données contient les tables suivantes :

- societes
- sites_miniers
- employes
- productions

## Compétences développées

- Modélisation de données
- Création de tables
- Clés primaires et étrangères
- Requêtes SQL
- Jointures
- Agrégations
- Analyse de production minière

## Outils utilisés

- PostgreSQL
- pgAdmin

## Résultats

✅ Création d'une base relationnelle complète

✅ Gestion des informations sur les sociétés minières

✅ Gestion des employés et sites miniers

✅ Analyse des volumes de production

✅ Réalisation de requêtes d'analyse SQL
