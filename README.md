# ⛏️ Gestion des Activités Minières au Mali

## Description

Projet SQL réalisé avec PostgreSQL simulant la gestion d'activités minières au Mali.

La base de données est composée de quatre tables :

- `societes`
- `sites_miniers`
- `employes`
- `productions`

Le projet permet d'effectuer plusieurs analyses telles que :

- le suivi des sites miniers ;
- l'analyse des salaires ;
- le calcul des productions ;
- le suivi des incidents de sécurité ;
- l'étude des minerais exploités.
